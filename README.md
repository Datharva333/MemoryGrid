# MemoryGrid

MemoryGrid is a lightweight educational website for exploring the evolution of computer memory and experimenting with dynamic memory allocation.

## Included

- Memory technology timeline
- First Fit, Best Fit, and Worst Fit heap allocation
- Allocation/free visualization with coalescing
- External fragmentation and utilization statistics
- Scriptable allocation playground
- Small strategy comparison benchmark
- Open learning resources and references

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
npm start
```

## Stack

Next.js, React, TypeScript, Tailwind CSS.
